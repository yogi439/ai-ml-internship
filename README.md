# Artificial Intelligence & Machine Learning Internship — Yogi439

This repository contains the completed internship tasks, from data exploration through model training, evaluation, and an interactive prediction app.

## Tasks
1. **Data Exploration** — Titanic dataset loading, inspection, cleaning, and visualization.
2. **Machine Learning Model** — Logistic Regression pipeline for survival prediction.
3. **Model Evaluation & Prediction** — metrics, confusion matrix, ROC-AUC, and example predictions.
4. **Interactive Application** — Streamlit app for making Titanic survival predictions.

## Setup
```bash
pip install -r requirements.txt
```

Run the application:
```bash
streamlit run task4_streamlit_app.py
```

The project downloads the public Titanic dataset at runtime, so no dataset is committed to the repository.
